Smooth Driver

A chime when you’re getting close to a hard brake or fast start, before Snapshot counts one. Snapshot’s line is about 7 mph per second.

  1. Mount this phone firmly, in any position. If it slides, you’ll get false alerts.
  2. Turn the ringer switch on and the volume up.
  3. Tap Start and allow motion and location. Leave this screen open.
  4. Drive normally for a few minutes. It learns which way is forward from your first few starts and stops.
