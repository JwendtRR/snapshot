Smooth Driver

A chime when you’re getting close to a hard brake or fast start, before Snapshot counts one. Snapshot’s line is about 7 mph per second.

  1. Mount this phone firmly, in any position. If it slides, you’ll get false alerts.
  2. Turn the ringer switch on and the volume up.
  3. Tap Start and allow motion and location. Leave this screen open.
  4. Drive normally for a few minutes. It learns which way is forward from your first few starts and stops.

GPS + sensors: the motion sensor gives the early warning, and GPS speed changes catch long, steady speed-ups or slow-downs that the sensor can miss. It also ignores sudden stops from walking speed, since you can’t lose 7 mph in a second when you’re only going 3. Sensors only means GPS isn’t giving a speed right now, so readings are less reliable.

Use “Relearn” if you move the phone. Until it has learned forward, sharp turns can set off the chime too. Readings from a phone are approximate, so the alert sits a little under Snapshot’s 7 mph per second line on purpose.
